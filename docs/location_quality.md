# 位置の信頼度（要確認マーク）— 調査結果と今後の修正予定

調査日: 2026-11-02 ／ きっかけ: 慶良間諸島の南の海上に、2024-03-24 の地衣類が登録されていた。

## 調査結果
- 該当は2024-03-24の21枚（15:19〜15:22、デジカメ TG-6）。写真は**本物の地衣類**（コンクリートの構造物と草）で、撮影場所が誤っているだけ。
- 原因: TG-6 の写真には GPS が無く、lichens の位置推定が `sameday`（同じ日の iPhone の GPS 写真のうち、撮影時刻が最も近いものの近くに置く）で決めていた。参照した iPhone 写真は**約2.6〜2.7時間離れており、海上（移動中の船上と思われる）**だった。
- 同じ原因の海上の推定位置を調べた（推定位置2,249枚・466地点を、国土地理院の標高APIで確認）: 標高データなし（海上・範囲外）は **27地点・47枚**（2024-03-24 の21枚、2024-09-14 の9枚、2024-10-13 の17枚）。すべて公開分。
- 推定位置の内訳: 要確認 111件（note付きの `sameday` 59件・`manual` 26件、海上47件の合算で重複を除く）、推定 2,138件（補間・最寄り・1日以内の引き継ぎ）。

## 実施した修正（2026-11-02）
- 地図（`web/app.js`）:
  - 位置が「要確認」の点を、**赤い破線の丸**で表示。ポップアップに「⚠ 位置要確認（理由）」。
  - 位置が「推定」の点は、ポップアップに「位置は撮影時刻などから推定した値です」。
  - **標高データなし（海上・範囲外）の位置は、データの印がなくても、ポップアップで自動的に警告**（今後の登録も対象）。
  - 投稿フォームに「位置が不確か（要確認のマークを付ける）」を追加。選んだ位置が海上なら自動でチェックされる。
- データ: 位置の信頼度は `points.extra` の `位置`（要確認／推定）と `位置メモ`（理由）で持つ。
- ツール:
  - `tools/import_lichens.py`: 取り込み時に note / est から印を付ける（今後の取り込み用）。
  - `tools/flag_locations.py`: **登録済みの点**に印を付ける（`--check-sea` で海上チェック）。要確認111件・推定2,138件が対象。**反映には、一時的な secret key を作って実行する必要があり、未実施**（実行手順は下記）。位置そのものは変えない。

## 反映手順（未実施）
1. Supabase の API Keys で、一時的な secret key を作る（説明例: `位置フラグ付与用・作業後に削除`）。
2. `map_registry/.env` に `SUPABASE_URL` / `SUPABASE_SECRET_KEY` を書く。
3. ドライラン: `python3 tools/flag_locations.py --src ../lichens/map_local --check-sea`
4. 反映: 同じコマンドに `--apply`。
5. 終わったら secret key と `.env` の該当行を削除。

## 今後の修正予定（優先順）
1. **上記の印の反映**（flag_locations.py の実行）。
2. **該当47枚の本来の位置を確認して修正**: 2024-03-24（21枚。慶良間諸島のいずれかの島の可能性）、2024-09-14（9枚）、2024-10-13（17枚）。場所が分かれば、lichens の `scripts/manual_locations.json` に日付ごとの位置を入れて再生成する。分からなければ「位置不明」に戻し、地図から外す。
3. **位置推定の改善（lichens 側 `estimate_locations.py`）**: `sameday` は時間差の上限を設ける（例: 2時間超は地図に載せない）。方法（interp／nearest／carry／sameday／manual）と時間差を、公開データ（photos.json）にも持たせ、信頼度を細かく表示する。
4. **地図に絞り込みを追加**: 「要確認のみ表示／非表示」。凡例（赤い破線＝要確認）を表示。
5. **管理者が地図上で位置を修正する機能**（表示位置と非公開の正確な位置の両方を更新。監査ログ付き）。
6. **移動中の写真の検出**: 船・車での移動中（海上や、前後の位置が速く動いている）の写真を、自動で要確認にする。海上以外にも、湖・海岸線の外の判定を検討。
7. 利用者の通報: ポップアップから「位置が違う」を通報できるようにする（通報テーブルは作成済み）。
